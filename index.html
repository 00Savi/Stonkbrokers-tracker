Methodology & Disclaimer

Methodology: Cash-on-Cash (CoC) return metrics are calculated using a Dual-Capture Oracle Model to ensure absolute on-chain accuracy. The tracker samples the trailing 7-day realized Native ETH and tracked ERC-20 token distributions sent to a representative, fully active Partner (T4) wallet. This baseline calculates the exact yield per weight unit, which is then mathematically extrapolated across the live active network weight. This global yield is annualized and evaluated against the current AMM floor purchase costs plus tier activation requirements.

Disclaimer: Tracked yield values are calculated using Mark-to-Market spot pricing at the exact time of the dashboard's last automated sync, rather than the historical price at the time of the drop. Yields fluctuate based on network activation weight, market token prices, and community protocol volume. This is a community-built tracking tool and does not guarantee future returns.
